Welcome aboard

This is an early playable flight-deck prototype. Pick a starting position and explore the controls. Flight dynamics are simplified for fun and learning—not for real-world training or navigation.

Keyboard controls

↑ / ↓ pitch · ← / → roll · W / S thrust · B parking brake · G landing gear · F cycle flaps · / spoilers · P autopilot · L lights · C camera · R reset · Space pause

Getting airborne

Start on a runway, release the parking brake, set flaps, then add thrust. At about 145 kt, gently pull up. Keep wings level and gear up after a positive climb. The assisted mode provides gentle stability and guidance.
